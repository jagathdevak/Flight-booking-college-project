## 📌 About the Project

Omega Airlines is a college web development project built using PHP and MySQL. It simulates an airline booking website with flight search, destination browsing, customer support, and a client portal.

🔗 **Live Demo:** [omega-airlines-jagath.42web.io](https://omega-airlines-jagath.42web.io/)

## ✨ Features

- ✈️ Airline-themed homepage and flight search interface
- 🌍 Destination browsing
- 🧳 Travel experience page
- 🎫 Flight booking workflow
- 👤 Client portal
- 💬 Customer support system
- 🗄️ MySQL database integration

## 🚀 Run Locally

1. Install a local PHP environment such as XAMPP.
2. Clone or download this repository.
3. Place the project folder inside your server's `htdocs` directory.
4. Create a MySQL database and configure `includes/db.php` with your local database credentials.
5. Start Apache and MySQL.
6. Open the project through your local server in a browser.

**Note:** The live hosting configuration may differ from your local setup. Never commit database passwords or other secrets to a public repository.
